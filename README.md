# Trabalho de TSI do primeiro semestre da matéria de Desenvolvimento Front-End I.
Este é o trabalho da disciplina de Desenvolvimento Front-End I, parte do curso de Tecnologia em Sistemas para Internet (TSI - UTFPR).
Desenvolvido para consolidar os conhecimentos adquiridos no primeiro semestre, o projeto explora a aplicação prática de HTML, CSS e diferentes frameworks, integrando teoria e desenvolvimento web.
